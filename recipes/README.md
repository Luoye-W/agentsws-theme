# Recipes

Standard ways to handle common operator requests. Each recipe starts by checking whether a lower rung (see AGENTS.md §1) is enough.

| The operator says… | Rung | Recipe |
|---|---|---|
| "Change colors / fonts / button shape / page width" | L0 | [change-style.md](change-style.md) |
| "Add a section with a title, text and a button to the homepage" | L2 | [compose-page.md](compose-page.md) |
| "Make a landing page for a campaign" | L2 | [compose-page.md](compose-page.md) |
| "Add something the theme doesn't have (badges row, custom banner, special table…)" | L3 | [add-custom-block.md](add-custom-block.md) |

More recipes arrive with batches 2–6 (product page, cart, collections, migration from other themes).
If no recipe fits, follow AGENTS.md and write the new recipe after you finish.
